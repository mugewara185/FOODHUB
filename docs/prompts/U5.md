### Step 2.3 — Add risk state to useAdminFleet

Open `web/src/features/admin/hooks/useAdminFleet.ts`.

Add a `risks` state:
```typescript
const [risks, setRisks] = useState<any[]>([]);
```

In the socket subscription block, add listeners for `delivery:risk` and `delivery:risk_cleared`:
```typescript
socketService.onAdminFleetEvent('delivery:risk', (riskData) => {
  setRisks(prev => [...prev.filter(r => r.deliveryId !== riskData.deliveryId), riskData]);
});
socketService.onAdminFleetEvent('delivery:risk_cleared', (data) => {
  setRisks(prev => prev.filter(r => r.deliveryId !== data.deliveryId));
});
```

Return `risks` from the hook alongside the existing return values.

### Step 2.4 — Render risk alerts in AdminDeliveryDashboard

Open `web/src/pages/admin/delivery/index.tsx`.

1. Destructure `risks` from `useAdminFleet()`.
2. After the connection status indicator (around line 48–50), add:
   ```tsx
   {risks.length > 0 && risks.map((risk, i) => (
     <Alert key={i} severity="warning" sx={{ mb: 1 }}>
       Risk alert — Delivery {risk.deliveryId}: {risk.reason ?? 'Unknown risk'}
     </Alert>
   ))}
   ```
   Import `Alert` from `@mui/material` if not already imported.
