## PHASE 2 — Apply

### Step 2.1 — Add `deliveryCompleted` reducer action

Open `web/src/features/deliveryPartner/deliveryPartnerSlice.ts`.

In the `reducers` object of the slice, add a new reducer:
```typescript
deliveryCompleted(state, action: PayloadAction<DeliveryAssignment>) {
  const assignment = action.payload;
  // Push to history if not already present
  if (!state.history.find(h => h.id === assignment.id)) {
    state.history.unshift({ ...assignment, status: 'delivered' });
  }
  // Update stats
  state.stats.todayDeliveries += 1;
  state.stats.todayEarnings += assignment.earnings ?? 0;
  state.stats.totalEarnings += assignment.earnings ?? 0;
  // Clear active assignment
  state.activeAssignment = null;
  state.status = 'ONLINE';
  state.isOnline = true;
},
```
