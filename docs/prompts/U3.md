Reference: docs/uiCompletionPlan.md Section 8, "U3"

## PHASE 2 — Apply

Open `web/src/pages/_ownerPages/DashBoard.tsx`.

Replace the entire file content with a new implementation that:

1. **Removes** the `fetchOwnerData` + `ownerSlice` dependency entirely.
2. **Reads from `ownerOrders` slice**: `state.ownerOrders.pendingOrders`, `state.ownerOrders.activeOrders`, `state.ownerOrders.isLoading`.
3. **Reads from `ownerRestaurant` slice**: restaurant name, rating, isOpen status.
4. **Renders**:
   - A stat row: pending orders count, active orders count, restaurant rating.
   - Restaurant name and open/closed status badge.
   - A list of the last 5 `pendingOrders` with order ID (shortened), total, and status chip.
   - A list of the last 5 `activeOrders` with order ID, total, and status chip.
   - Loading spinner when `ownerOrders.isLoading` is true and both lists are empty.
   - Empty state when both lists are empty and not loading.
5. **Preserves** all existing MUI imports that are still needed; remove unused ones.
6. **Does NOT** dispatch any new thunks — data is already fetched by `OwnerLayout`.
7. **Does NOT** use `useOwnerSocket()` — already called by `Queue.tsx` and `Active.tsx`.

Do not use `ownerSlice` or `fetchOwnerData` anywhere in the new file.
